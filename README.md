# رحلة فاطمة

موقع عائلي عربي لإدارة مهام فاطمة، مراجعة إنجازاتها، جمع النجوم، وطلب المكافآت. الواجهة مبنية بـ Next.js، والمصادقة والبيانات المشتركة تستخدم Supabase. التصميم متجاوب للجوال والآيباد والكمبيوتر.

## ما يعمل في هذا الإصدار

- دخول فاطمة برمز رقمي من ستة أرقام، ودخول ولي الأمر بالبريد وكلمة المرور.
- فصل الواجهة حسب الدور المخزن في `profiles`.
- إدارة المهام والمكافآت من لوحة ولي الأمر.
- إرسال إنجاز للمراجعة، واعتماده أو إعادته.
- جمع النجوم وطلب المكافآت، مع التحقق من الرصيد داخل قاعدة البيانات.
- سجل للإنجازات وموجز أسبوعي.
- حفظ سحابي وسياسات صلاحيات على مستوى الصفوف في Supabase.
- مزامنة فورية للتغييرات بين الأجهزة عبر Supabase Realtime.

## المتطلبات

- Node.js 20.9 أو أحدث.
- مشروع Supabase.

## التشغيل المحلي

1. أنشئ مشروعًا في Supabase.
2. من **Project Settings → API** انسخ **Project URL** و**Publishable key**.
3. أنشئ ملف `.env.local` بجانب `package.json`:

   ```env
   NEXT_PUBLIC_SUPABASE_URL=https://your-project.supabase.co
   NEXT_PUBLIC_SUPABASE_ANON_KEY=your-publishable-key
   ```

4. افتح **SQL Editor** في Supabase وشغّل محتويات [`supabase/schema.sql`](supabase/schema.sql).
5. من **Authentication → Users** أنشئ حساب ولي الأمر ببريده وكلمة مروره. أنشئ حساب فاطمة ببريد الدخول الثابت `fatima@fatoom-s-journey.app` واجعل كلمة مروره رمزًا رقميًا من ستة أرقام تختاره أنت. لا تضع الرمز في المستودع أو تشاركه علنًا. واجهة الموقع لا تعرض بريد فاطمة؛ هي تدخله تلقائيًا عند كتابة الرمز.
6. انسخ معرّف المستخدم (UUID) لكل حساب من صفحة المستخدمين. في آخر `supabase/schema.sql` يوجد استعلام إعداد العائلة؛ أزل التعليقات عنه، واستبدل `PARENT_AUTH_USER_UUID` و`CHILD_AUTH_USER_UUID` بالمعرّفين الحقيقيين، ثم شغّله مرة واحدة في SQL Editor.
7. ثبّت الحزم وشغّل الموقع:

   ```bash
   pnpm install
   pnpm dev
   ```

8. افتح `http://localhost:3000` وسجّل الدخول بأحد الحسابين.

## النشر

ارفع المشروع إلى مستودع GitHub ثم استورده في Vercel. أضف متغيري `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_ANON_KEY` إلى إعدادات المشروع في Vercel، ثم انشره. لا تضع `service_role` أو أي سر إداري في متغير يبدأ بـ `NEXT_PUBLIC_`.

إذا فعّلت قيود إعادة التوجيه في Supabase Auth، أضف عنوان الموقع المنشور إلى قائمة **Site URL** و**Redirect URLs**. سجّل الدخول مطلوب على كل جهاز؛ البيانات نفسها تظهر لكل حساب وفق صلاحياته. ملف SQL يضيف جداول المهام والمراجعات والمكافآت إلى `supabase_realtime` حتى تتحدث الشاشات المفتوحة تلقائيًا.

## الأمان والبيانات

كل جداول العائلة مفعّل عليها Row Level Security. حساب الطفلة يستطيع رؤية بيانات العائلة وإرسال إنجازاته وطلب المكافآت، بينما اعتماد النقاط وإدارة المهام والمكافآت مقصوران على حساب ولي الأمر. استخدموا كلمات مرور فريدة للحسابين ولا تنشروا مفاتيح خاصة في المستودع.

## ملاحظات الإصدار الأول

- إنشاء حساب ولي الأمر وحساب فاطمة يتم من لوحة Supabase أول مرة. حساب فاطمة له هوية Auth مستقلة، ويُستخدم الرمز ذو الستة أرقام ككلمة مروره حتى تبقى صلاحيات قاعدة البيانات منفصلة عن صلاحيات ولي الأمر.
- رصيد النجوم محسوب من الإنجازات المعتمدة ناقص المكافآت المصروفة؛ لا يمكن للمتصفح تعديل الرصيد مباشرة.
- المزامنة الفورية تتطلب تفعيل Realtime للجداول بنجاح عند تشغيل `schema.sql`، واتصال الأجهزة بالإنترنت.
